# 羽毛球比赛录像收藏

本项目用于整理和记录羽毛球比赛录像，主要收录世界羽联高级别巡回赛、国际综合运动会、世界锦标赛及经典球员对决。

## 项目概况

- **当前已下载：274 场比赛**
- **主要统计年份：2022—2026 年**
- **补充赛事年份：2021 年及其他经典比赛**
- **数据文件：`matches.xlsx`**
- **最后更新：2026-08-12**

> 比赛数量以已经下载并完成整理的独立场次为准，不等于 Excel 中的赛事数量。

---

## 收录范围

世界羽联高级别赛事，重大团体杯赛，洲际锦标赛，综合运动会等

---

## 文件说明

### `matches.xlsx`

Excel 文件包含两个工作表：

#### 1. 重大赛事

用于记录高级别巡回赛和国际重大赛事。

主要字段：

| 字段 | 说明 |
|---|---|
| 年份 | 赛事所属年份 |
| 赛事中文名 | 赛事中文名称 |
| 决赛 | 决赛录像下载或整理状态 |
| 半决赛 | 半决赛录像下载或整理状态 |
| 开始日期 | 赛事开始日期 |
| 结束日期 | 赛事结束日期 |
| 赛事英文名 | 赛事英文名称 |
| 赛事级别 | Super 500、Super 750、Super 1000 等 |
| 国家或地区 | 赛事举办国家或地区 |
| 城市 | 赛事举办城市 |

#### 2. 其他赛事

用于记录不在主要赛历内的比赛及专题合集。

主要字段：

| 字段 | 说明 |
|---|---|
| 年份 | 比赛或合集所属年份 |
| 赛事中文名 | 赛事、球员或专题名称 |
| 备注 | 比赛轮次、球员姓名和整理数量等信息 |
| 开始日期 | 赛事开始日期 |
| 结束日期 | 赛事结束日期 |
| 赛事英文名 | 赛事英文名称 |
| 赛事级别 | 赛事等级 |
| 国家或地区 | 举办国家或地区 |
| 城市 | 举办城市 |
